# Chroma Vault

Chroma Vault is an original browser maze inspired by the bold colours and command-driven adventures of the BBC Micro era.

Open [dist/index.html](dist/index.html) in a browser to play. The game runs locally without a server or dependencies.

- Use the up and down arrow keys to move and the left and right arrow keys to turn.
- Type `LOOK` to inspect your location, or use **ACT** to interact with what you find.
- The compass map fills in as you explore. The **CARRYING** line shows your inventory.
- Type `RESTART` to start over.

A hungry gorilla guards the exit. Somewhere in the maze are a dragon, a thirsty palm, an ice block, and an empty bucket.
